# 📄 DocuMind-AI

An AI-powered PDF Analysis API built using FastAPI and Python.

## 🚀 Features

- 📤 Upload PDF
- 📖 Read PDF
- ✂️ Chunk PDF
- 📝 Summarize PDF
- 🔑 Extract Keywords
- 📊 PDF Analytics
- 📑 PDF Metadata
- 🔍 Search Keyword in PDF
- ⏱️ Reading Time Estimation
- 📈 Word Frequency Analysis
- 📥 Export Summary as TXT
- 📋 Dashboard API

## 🛠️ Tech Stack

- Python
- FastAPI
- PyMuPDF (fitz)
- Sumy
- YAKE
- NLTK

## 📦 Installation

```bash
git clone https://github.com/monisha2502/DocuMind-AI.git
cd DocuMind-AI
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## 📚 API Endpoints

| Endpoint | Description |
|----------|-------------|
| /upload | Upload PDF |
| /read-pdf | Read PDF |
| /chunk-pdf | Chunk PDF |
| /summarize | Summarize PDF |
| /keywords | Extract Keywords |
| /analytics | PDF Analytics |
| /metadata | PDF Metadata |
| /search | Search Text |
| /reading-time | Estimate Reading Time |
| /word-frequency | Most Frequent Words |
| /dashboard | Overall Dashboard |
| /export-summary | Download Summary |
